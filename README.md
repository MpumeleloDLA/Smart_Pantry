The smart food pantry application has been developed to assist users track down items, the ingredients used to make better healthy options for themselves.

#So this acts as a pantry that features an inventory of keeping track of the food you eat such as the quantities, category of the food and expiration dates.
The use of a room database that is for the local storage for the users data.
The use of a recycleview UI that allows for user-friendly list for the items
the use of xml and manifest to design my project 

#how it was built
The language used: Java
The database was sqlite Room database
the UI component: RecycleView, CardView
